## 依赖概览

```
P0 基建(G1→G2→G3)
        │
P1 ┌────┴────┐
 L1(内容获客)  L2(线索自动化)
 │  └─ M1→M2→M3→M4        L2.1→…→L2.5
 └──────┬──────────────┘
P2 L3 潜客识别(依赖 L1 回流 + L2 数据)
P3 L4 售前服务(依赖 知识资产治理 + 红线就绪)
L5 赋能 = 全程横切,随各闭环沉淀
```

依赖原则:**先建三资产(G2),闭环只"填充+消费";L3 依赖 L1/L2 数据回流;L4 最深最后。**
