## 背景

## 裁定

| ID | 决定 | 理由 | 反悔成本(改动影响) |
|---|---|---|---|
| A1 | 首期语言 **EN(全球)+ DE(德/奥/瑞)**;二期 西/荷/法/阿 | DACH/Benelux 为工商业储能最热区;多语言是产能瓶颈 | 语言 pipeline、术语表范围 |
| A2 | 渠道优先级 **LinkedIn 企业号 > SEO 博客 > 阿里国际站多语言详情页**;短视频先产脚本 | B2B 长决策买家在 LinkedIn ROI 最直接;独立站平台未定不阻塞 | 模板组、回流字段 |
| A3 | 素材现状中文为主、英文不全 → **先事实卡片化,中文为主源译制** | 防 AI 幻觉的唯一可靠载体(红线1) | 卡片工作量与译制校验 |
| A4 | 默认 **1 位业务负责人审校**;基线 3 篇/周 → 目标 8~10+/周 **不加人** | 审校是瓶颈,目标按"不加人提产能"设定 | 审校队列吞吐设计 |
| A5 | 无独立站/博客平台信息 → **按"有站可发"预留**,先不阻塞生产 | 避免平台未定拖死内容生产 | 发布步骤具体形式 |
| R1 | 技术内容只准引用 Facts,新事实入 Facts 前不得进正文 | 储能技术/合规表述是致命风险点 | 写作自由度(接受) |
| R2 | 复杂售前默认人机协同;对外内容必须人审 | B2B 大客单,报价/承诺由人确认 | 自动化上限(接受) |
| R3 | 每闭环上线挂指标,用数据验收 | 防"工具做了无业务价值" | 无(正向约束) |

## 开放问题(不阻塞开工,见 L1 spec §10)

- 独立站/博客平台是否存在(A5 待证)
- 主力在售产品线与认证清单(→ M1.1 盘点)
- 审校人力是否单人(先按单人设计)
